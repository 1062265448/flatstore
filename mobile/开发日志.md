# Flatstore Mobile - 开发日志

---

## 2026-05-09

### 项目初始化

- 创建 `D:\Flatstore\mobile` 项目
- 技术栈：Vue 3 + TypeScript + Vite 6 + Pinia + Vue Router + Axios
- Capacitor 7 原生包装（Android 平台）

### 架构决策

| 决策 | 说明 |
|------|------|
| 框架 | Vue 3 Composition API，与现有 Web 前端保持一致 |
| 打包 | Capacitor（非 uni-app），保留全部 Vue 代码 |
| 样式 | 纯 CSS + CSS 变量，不使用 UI 组件库 |
| 图标 | 不使用 emoji 和小图标，全部用文字标签 |
| 主题 | 亮色基调（`#FAFAFA` 背景，`#0066FF` 主色） |

### 页面开发

| 页面 | 文件 | 功能 |

### API 层

- `api/request.ts`：Axios 封装，自动检测环境（Capacitor → localhost:3002 / 浏览器 → Vite 代理）
- `api/distribution.ts`：全部业务 API 接口
- `composables/useImagePicker.ts`：Capacitor 原生相机/相册 vs 浏览器 file input
- `composables/useToast.ts`：Toast 系统（替代 Element Plus）

### 后端配置

- 修复 CORS：`backend/src/main.ts` 改为支持多来源（含 `capacitor://localhost`）
- 后端 `.env` 添加多个前端地址

### Capacitor 配置

- 平台：Android（`android/` 原生工程）
- 插件：camera、filesystem、haptics、status-bar、splash-screen、app
- 权限：INTERNET、CAMERA、READ/WRITE_EXTERNAL_STORAGE
- 网络安全：`network_security_config.xml` 允许 HTTP 明文
- `capacitor.config.ts`：默认使用本地 dist 打包，开发时可切换 live reload

### 连接方式

| 场景 | 方式 |
|------|------|
| 手机 ↔ 后端（同一 WiFi） | 局域网 IP 直连 |
| 手机 ↔ 后端（不同 WiFi） | ADB reverse（USB 反向代理） |
| 浏览器开发 | Vite dev server + proxy |
| App 热更新 | capacitor.config.ts server.url 指向 Vite 地址 |

### 环境配置问题修复

| 问题 | 修复 |
|------|------|
| CORS 拦截登录 | 后端 `main.ts` 改为多来源支持（含 `capacitor://localhost`） |
| Android Studio 未安装 | 安装至 `D:\programs\android studio`，设置 JAVA_HOME |
| Gradle 下载超时 | 下载源改为腾讯镜像，Maven 改为阿里云镜像 |
| 401 自动跳转导致请求中断 | 移除 `window.location.href = '/login'`，改为静默清除 token |
| ADB 反向代理 | `adb reverse tcp:3002 tcp:3002`（USB 反向代理） |
| TabBar 使用特殊字符图标 | 改为纯文字标签 + 下划线指示器 |
| 登录错误信息不显示 | 修复错误消息提取逻辑，适配已解包的响应拦截器 |

### AI 识别问题排查

| 问题 | 原因 | 修复 |
|------|------|------|
| AI 识别只显示 1 条数据 | 后端返回 `{ results: [...], historyId: N }`，前端只取第一条 | 改为遍历所有 results |
| AI 类型定义不匹配 | `aiRecognize` 返回类型声明为 `AiRecognizeResult[]` | 改为 `{ results: [...], historyId: N }` |
