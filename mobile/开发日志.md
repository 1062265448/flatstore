# Flatstore Mobile - 开发日志

---

## 2026-05-09 — v1.0.0 正式发布

### 项目概述

Flatstore Mobile 是平面库配货系统的手机端应用，基于 **Vue 3 + TypeScript + Vite + Capacitor 7** 构建，提供原生 Android App 体验。与 Web 前端和后端共享同一数据库，实现数据完全同步。

**包名**: `com.flatstore.mobile`
**构建时间**: 2026-05-09 17:30

### 核心功能

| 模块 | 功能 |
|------|------|
| 登录认证 | JWT 认证、登录/注册切换、401 静默处理 |
| 首页 | 实时统计数据、库存分布可视化、最近配货单、AI 快捷入口 |
| 库存管理 | 搜索、品级筛选、卡片列表、分页加载、库存详情、编辑/删除 |
| 配货单管理 | 状态筛选、新建配货单（BottomSheet + 库存选择）、详情、发货/完成/取消 |
| AI 识别 | 原生相机/相册、识别历史、结果展示、批量导入库存 |
| 个人中心 | 用户信息、快捷入口、退出登录 |

### 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Vue 3 Composition API + TypeScript |
| 构建 | Vite 6 |
| 状态 | Pinia |
| 路由 | Vue Router 4 |
| HTTP | Axios（响应解包 + JWT 注入） |
| 原生 | Capacitor 7（Android） |
| 插件 | camera、filesystem、haptics、status-bar、splash-screen、app |
| 样式 | 纯 CSS + CSS 变量，无 UI 组件库 |
| 数据库 | MySQL 8.0（与 Web 前端共享） |
| 后端 | NestJS 10 + Prisma 6 |

### 架构决策

| 决策 | 说明 |
|------|------|
| 框架 | Vue 3 Composition API，与现有 Web 前端保持一致 |
| 打包 | Capacitor（非 uni-app），保留全部 Vue 代码 |
| 样式 | 纯 CSS + CSS 变量，不使用 UI 组件库 |
| 图标 | SVG 矢量图标（TabBar），状态用圆点+文字标签 |
| 主题 | 亮色基调（`#FAFAFA` 背景，`#0066FF` 主色） |
| 连接 | ADB 反向代理（USB）/ 局域网 IP 直连（WiFi） |
